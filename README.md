# ATM Machine Simulation

A simple *ATM Machine Simulation developed using Java*. This console-based application simulates common ATM operations such as checking account balance, depositing money, withdrawing money, and exiting the application.

## 👨‍💻 Author

*Arjun Sharma*

Java Backend Developer | Java | Spring Boot | MySQL

## 🚀 Features

- PIN authentication
- Check account balance
- Deposit money
- Withdraw money
- Balance validation
- Insufficient balance handling
- Menu-driven interface
- Exit option
- Console-based user interaction

## 🛠️ Technologies Used

- Java
- Core Java
- Scanner
- Variables and Data Types
- If-Else Statements
- Switch-Case
- Loops
- Methods
- Basic Object-Oriented Programming
